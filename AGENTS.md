# Development instructions for Kite Native

This repository is the native (SchildiChat Revenge) implementation of Kite. Read `MIGRATION.md` first; it is the durable migration ledger and acceptance checklist. The authoritative original Flutter client is `/home/brandon/kite` on Glass, READ ONLY. Performance is more important than animation polish. Preserve source licensing, frame-time performance and existing Matrix features. Incrementally port Kite icon, colour scheme, chat/reaction UI and gestures to Compose; do not reimplement with Flutter. Never overwrite, uninstall or reset `app.kite` or production Matrix accounts. Use the unique test package `app.kite.revenge.debug` for debug builds. Commit coherent verified slices, then update the ledger with exactly what was tested and not yet tested. The Prompta job name is `kite-revenge-native` (45 min cadence). Avoid running builds/tests in parallel with another Kite native worker; inspect git status before changes. Do not run heavy package jobs when storage or system health is degraded.
