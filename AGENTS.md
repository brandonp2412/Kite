# Development instructions for Kite Native

This repository is Kite, a native Matrix client forked from SchildiChat Revenge. Read `MIGRATION.md` first; it is the durable migration ledger and acceptance checklist. The original Flutter client is archived at `~/.archived/kite` on Glass, READ ONLY. Performance is more important than animation polish. Preserve source licensing, frame-time performance and existing Matrix features. Incrementally port Kite icon, colour scheme, chat/reaction UI and gestures to Compose; do not reimplement with Flutter. Never overwrite, uninstall or reset `app.kite` or production Matrix accounts. Before building or installing a public release, fetch the live `origin/main` and verify the release commit descends from it (`git merge-base --is-ancestor origin/main HEAD` after fetch); reconcile divergent Glass/Nox histories first. Do not ship from stale detached worktrees. Use `app.kite` for all public Android build types. Existing `app.kite.revenge.debug` installations have independent data and must not be reset. Commit coherent verified slices, then update the ledger with exactly what was tested and not yet tested. Avoid running builds/tests in parallel with another Kite native worker; inspect git status before changes. Do not run heavy package jobs when storage or system health is degraded.

Glass build environment: set `JAVA_HOME=/usr/lib/jvm/java-25-openjdk`, `PATH=$JAVA_HOME/bin:$PATH`, and `ANDROID_HOME=/opt/android-sdk` for Gradle. `cargo-ndk` and the Rust Android targets are installed. Do not run multiple overlapping Android builds; native Rust SDK FFI compile is expensive.

- Do not install package-rename builds onto Samsung until migration and signing are verified. Build `:androidApp:assembleRelease -PandroidAbi=arm64-v8a`, verify the APK package is `app.kite` and its signer matches any previously installed `app.kite`. Never uninstall or reset the app to resolve a signing/version mismatch.
