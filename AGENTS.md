# Development instructions for Kite Native

This repository is the native (SchildiChat Revenge) implementation of Kite. Read `MIGRATION.md` first; it is the durable migration ledger and acceptance checklist. The authoritative original Flutter client is `/home/brandon/kite` on Glass, READ ONLY. Performance is more important than animation polish. Preserve source licensing, frame-time performance and existing Matrix features. Incrementally port Kite icon, colour scheme, chat/reaction UI and gestures to Compose; do not reimplement with Flutter. Never overwrite, uninstall or reset `app.kite` or production Matrix accounts. Use only the Android application ID `app.kite.revenge.debug` for every build type; never introduce another installable Kite Revenge package. Commit coherent verified slices, then update the ledger with exactly what was tested and not yet tested. The Prompta job name is `kite-revenge-native` (45 min cadence). Avoid running builds/tests in parallel with another Kite native worker; inspect git status before changes. Do not run heavy package jobs when storage or system health is degraded.

Glass build environment: set `JAVA_HOME=/usr/lib/jvm/java-25-openjdk`, `PATH=$JAVA_HOME/bin:$PATH`, and `ANDROID_HOME=/opt/android-sdk` for Gradle. `cargo-ndk` and the Rust Android targets are installed. Do not run multiple overlapping Android builds; native Rust SDK FFI compile is expensive.

- After successfully changing anything, install it on Samsung in release mode. Build `:androidApp:assembleRelease -PandroidAbi=arm64-v8a`, verify the APK package is `app.kite.revenge.debug` and its signer matches the installed app, then `adb install -r` to preserve existing data. Never uninstall or reset the app to resolve a signing/version mismatch.
