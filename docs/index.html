Kite Privacy Terms Support Source

Kite is an open-source Matrix client focused on fast, uncluttered messaging and a smooth mobile experience. It is based on FluffyChat and maintains its own interface, releases, support pages, and roadmap.

Open source

Kite is distributed under the same AGPL-3.0-or-later licensing basis as the upstream project. Source code, issue tracking, and releases are hosted on GitHub.
