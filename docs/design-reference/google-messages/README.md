# Google Messages Android visual reference

Pinned visual references for the native Kite redesign.

## Design direction

Google Messages / Material 3 Expressive is the primary visual reference for the native Kite UI.

**Intentional Kite exception:** keep Kite's existing inbox search bar at the **bottom**. Do not move search to the top merely to mirror Google Messages.

These images are reference material only. Preserve Kite branding, icon, Matrix-specific functionality, and native performance characteristics.

## Usage

Before changing a related Kite screen, compare the implementation against these pinned references and, when safe, the current installed Google Messages app. Prefer screenshot-based side-by-side QA. Do not interact with real SMS/RCS content merely to gather reference material.
