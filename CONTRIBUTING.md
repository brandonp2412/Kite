# Contributing to Kite

Contributions and bug reports are welcome through [GitHub issues](https://github.com/brandonp2412/Kite/issues) and pull requests to [Kite](https://github.com/brandonp2412/Kite/pulls).

Use focused changes, preserve Matrix interoperability and upstream attribution, and test Android and desktop behavior where relevant. Avoid committing account data, credentials, or screenshots of real messages. Follow existing licensing and include relevant test results with your pull request.

Kite is based on [SchildiChat Revenge](https://github.com/SchildiChat/schildi-revenge). Contributions intended for upstream should follow [their contribution guidelines](https://github.com/SchildiChat/schildi-revenge/blob/main/CONTRIBUTING.md).
